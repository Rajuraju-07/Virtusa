Job Summary

Virtusa Corporation is hiring QA Engineers to join its Digital Assurance team. This role is ideal for fresh graduates and early-career professionals interested in automation testing, quality engineering, API testing, and cloud-based test automation. You will work with Selenium, Java, CI/CD pipelines, and AWS to ensure high-quality software delivery.

Educational Qualification

  • B.E. / B.Tech / M.E. / M.Tech in Computer Science, IT, or related field.
  • Eligible Batch: 2025 / 2026.
  • Freshers and candidates with up to 3 years of experience can apply.

Key Responsibilities

  • Develop and execute UI, Backend, and API automation test cases.
  • Perform Regression, Integration, and Performance Testing.
  • Design and maintain scalable automation testing frameworks.
  • Create Selenium automation scripts using Java.
  • Develop BDD automation using Cucumber.
  • Integrate automated tests into CI/CD pipelines.
  • Perform cloud-based testing using AWS.
  • Manage defects and ensure overall software quality.
